# Predictive Maintenance for HVAC Systems

## Project Overview
This project focuses on predicting potential failures in Heating, Ventilation, and Air Conditioning (HVAC) systems using machine learning.

The project uses sensor-related data such as temperature, humidity, vibration, pressure, energy consumption, and runtime hours to identify possible equipment failures.

## Objectives
- Analyse HVAC sensor data.
- Perform data cleaning and preprocessing.
- Explore data using visualizations.
- Apply feature engineering and feature scaling.
- Train machine learning models to predict failures.
- Compare model performance using evaluation metrics.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models
1. Logistic Regression
2. Random Forest Classifier

## Project Workflow
1. Dataset creation and loading
2. Data understanding and exploration
3. Data preprocessing
4. Exploratory Data Analysis (EDA)
5. Feature engineering
6. Model training and testing
7. Model evaluation
8. Feature importance analysis
9. Conclusion and recommendations

## Evaluation Metrics
The models are evaluated using:
- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC Score
- Confusion Matrix
- ROC Curve

## Dataset
This project uses a synthetic HVAC dataset created for learning and demonstration purposes. It includes sensor readings and a failure label.

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the `.ipynb` file using Jupyter Notebook.
4. Run the notebook cells sequentially.

## Conclusion
This project demonstrates how machine learning can be used for predictive maintenance by analysing HVAC sensor data and identifying potential equipment failures. It also provides a comparison of two classification algorithms.

**Note:** The dataset is synthetic, so the results are for educational purposes and may not represent real-world HVAC system performance.
